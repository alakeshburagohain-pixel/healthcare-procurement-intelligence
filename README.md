# Healthcare Procurement Intelligence
### AI-Powered Procurement Assistant

**Project:** ABC Healthcare Network  
**Technologies:** SAP MM (ECC 6.0 EHP7), Power BI, n8n, AI Agent, Excel

## Project Overview
Healthcare Procurement Intelligence is a portfolio project designed to demonstrate how SAP MM concepts, data analytics, and AI-powered workflow automation can support healthcare procurement operations.

The solution analyses healthcare material master data, identifies potential procurement data exceptions, generates corrective recommendations, and delivers automated email reports.

## Key Components

### 1. SAP MM
- Healthcare material master design and practice.
- Material groups and units of measure.
- Purchasing and procurement process practice.
- RFQ creation and material data validation.

### 2. Power BI
- Procurement intelligence dashboard.
- Material master exception analysis.
- Data-driven procurement insights.

### 3. n8n Automation
- Excel-connected AI procurement assistant.
- Automated exception analysis.
- Priority-based workflow conditions.
- HTML-formatted Gmail alerts.

### 4. AI Procurement Assistant
- Identifies potential material master exceptions.
- Prioritises high-risk findings.
- Explains business impact.
- Recommends corrective actions.

## Important Project Scope
This is a portfolio and learning project. The AI assistant provides advisory recommendations based on project workbook data. It does not automatically update SAP.

SAP transaction limitations prevented completion of the PR/PO and goods receipt/invoice verification stages. These limitations are documented transparently in the project report.

The dashboard and AI analysis use project data, not a live SAP production connection.
